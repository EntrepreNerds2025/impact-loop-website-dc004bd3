Photos for the Impact Standard page (/impact-standard)
======================================================

Drop your real photos here with these EXACT names and they replace the
on-page placeholders automatically. No code change needed.

1) field-band.jpg
   Where it shows : full-width cinematic band right under the hero
   Best size      : ~2400 x 800 px  (wide, 21:7). Landscape.
   What to use    : a warm, wide shot of a youth program in session
                    (room, faces optional, movement, real setting)

2) moment.jpg
   Where it shows : the "Impact Report" sample card, next to a quote
   Best size      : ~800 x 800 px  (square, 1:1)
   What to use    : a staff member with a participant, candid

Tips
- JPG or WebP both work (keep the .jpg name, or update the src in
  src/components/standard/StandardVisuals.tsx if you prefer .webp).
- Compress before adding (aim under ~400 KB each) so the page stays fast.
- Get consent for any identifiable youth before publishing a photo.

Want more photo slots? The <ImagePlaceholder src="..." /> component is
exported from src/components/standard/StandardVisuals.tsx and can be
dropped anywhere on the page.
